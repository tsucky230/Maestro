# 工程別チェックリスト

> **使用方法**: 各工程の成果物完成時に、該当セクションのチェックリストを使って品質確認してください。
> すべての項目がチェックされるまで、工程完了としないでください。

---

## SWP.1 要求仕様定義 完了チェックリスト

### 成果物チェック

- [ ] 要求仕様書が `docs/templates/requirements-spec.md` テンプレートに基づいて作成されている
- [ ] 文書情報（文書ID、バージョン、日付等）が記入されている
- [ ] 背景・目的・スコープが記述されている

### USDM準拠チェック

- [ ] すべての要求に「要求」「理由」「仕様」が記述されている
- [ ] 要求は「目的語＋動詞」で簡潔に記述されている
- [ ] 理由には背景・根拠が明記されている
- [ ] 仕様は検証可能な形で具体的に記述されている

### トレーサビリティチェック

- [ ] すべての要求に `REQ-XXX` タグが付与されている
- [ ] すべての仕様に `SPEC-XXX` タグが付与されている
- [ ] タグの重複がない
- [ ] トレーサビリティマトリクス（Section 1）が更新されている

### 品質チェック

- [ ] 曖昧な表現（「など」「適切に」「必要に応じて」）がない
- [ ] 非機能要求（性能、信頼性、セキュリティ、保守性）が含まれている
- [ ] リスク分析が行われている
- [ ] `knowledge/review-perspectives.md` の「要求仕様レビュー観点」でチェック済み
