# Maestro

**ESPR 2.0準拠 クロスプラットフォーム ソフトウェア開発エージェントフレームワーク**

GitHub Copilot、Claude Code、Codex、Antigravity — どのAIエージェントでも同じプロセス・品質基準で開発を進めるためのフレームワークです。

---

## 特徴

- 🔄 **クロスプラットフォーム**: 4つのAIエージェントが同一のプロセス規約に従う
- 📋 **ESPR 2.0準拠**: V字モデルに基づく体系的な開発プロセス
- 📝 **USDM対応**: 要求→理由→説明→仕様の構造化された要求仕様
- 🔗 **完全トレーサビリティ**: REQ→SPEC→ARC→DET→SRC/UT→IT→QTのタグ追跡
- 🧠 **知見ライブラリ**: 人間の経験をAIが活用可能な形で蓄積・参照
- 🤝 **人間×AI協働**: AIが支援し、人間が判断する品質開発
- 🎼 **インタラクティブ起動**: エージェント起動時にメニューを提示し、適切なワークフローに誘導
- 🌿 **ブランチ戦略**: mainブランチをフレームワーク専用に保ち、プロジェクト作業は別ブランチで実施
- 🇪🇺 **EU CRA準拠**: SPDX 3.0 + CycloneDX 1.6 + CSV のSBOM出力、脆弱性管理
- 🔍 **OSSスニペット検出**: ソースコード内のOSSコード混入を自動検出
- 📋 **整合性レビュー**: 企画書↔仕様書↔設計書間の矛盾を体系的に検出
- 📓 **対話ログ**: 人間↔エージェント間のすべての対話を構造化して記録
- 📊 **メトリクス品質ゲート**: 工程別の定量的品質基準で品質を証明
- 🏗️ **アーキテクチャ適合度テスト**: 設計制約を自動テストで継続検証
- 📐 **形式的仕様記述**: 前提/事後条件、状態遷移表で仕様の曖昧性を排除
- ⚠️ **FMEA/FTA**: 故障モード影響解析で潜在リスクを設計段階で除去
- 🤖 **エージェント自己評価**: 成果物の品質を提出前に自動チェック
- 🔍 **レビュープロトコル**: ウォークスルー/インスペクションで体系的レビュー
- 🌐 **マルチプロジェクト学習**: プロジェクト横断でパターン・知見を蓄積

## クイックスタート

### 1. エージェントに開発開始を依頼する

どのAIエージェントでも、以下のように依頼するだけで規約に従った開発が始まります:

```
「新しいプロジェクト〇〇の要求をヒアリングしてください」
```

エージェントは `AGENTS.md` を読み込み、インタラクティブメニューを提示します:

```
🎼 Maestro — ESPR 2.0 ソフトウェア開発エージェント

何をお手伝いしましょうか？

1️⃣  新規プロジェクトを開始する（要求ヒアリングから）
2️⃣  既存プロジェクトの作業を継続する
3️⃣  成果物をレビューする（設計書、コード等）
4️⃣  成果物間の整合性をチェックする
5️⃣  テストを設計・実行する
6️⃣  既存の成果物を閲覧・検索する
7️⃣  フレームワーク自体を更新する（テンプレート、ルール等）
```

### 2. Antigravityの場合

```
/develop を実行してください
```

ワークフローに沿って、Step 0（起動メニュー）から案内されます。

## ブランチ戦略

```
main ブランチ
  │  ← Maestroフレームワークの更新のみ
  │
  ├── feature/<project>/<description>  ← プロジェクト作業用
  ├── review/<project>/<description>   ← レビュー作業用
  └── hotfix/<description>             ← フレームワーク修正用
```

mainブランチはフレームワーク自体を最新に保つための専用ブランチです。プロジェクトの成果物はすべて作業用ブランチで管理します。
